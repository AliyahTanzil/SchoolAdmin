# Windows Requirements for SchoolAdmin

## System Software
# Install via official websites or Winget
Git (https://git-scm.com/download/win)
Node.js >= 18.0.0 (https://nodejs.org/)
Android Studio (https://developer.android.com/studio)
OpenJDK 11+ (https://adoptium.net/)

## Build Tools
# Necessary for better-sqlite3 native compilation
# Install via: npm install --global --production windows-build-tools
# OR via Visual Studio Installer (Desktop development with C++)
Microsoft Visual C++ Build Tools

## Backend Dependencies (npm)
bcryptjs@^3.0.3
better-sqlite3@^8.4.0
express@^4.18.2
jsonwebtoken@^9.0.3

## Website Dependencies (npm)
react@^18.2.0
react-dom@^18.2.0
react-router-dom@^7.16.0
vite@^4.4.9
vitest@^0.34.1

## Mobile Dependencies (npm)
react@^18.2.0
react-native@^0.72.0

## Environment Variables
JAVA_HOME
ANDROID_HOME
PATH (include %ANDROID_HOME%\platform-tools)
