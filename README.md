# SchoolAdmin monorepo

This workspace contains three top-level folders:

- `Backend` — Node.js + Express API with Jest unit tests.
- `website` — Vite + React web app with Vitest tests.
- `mobileApp` — React Native starter with basic Jest test.

Quick commands (run inside each folder):

```bash
# Backend
cd Backend
npm install
npm test

# Website
cd website
npm install
npm run dev
npm test

# Mobile (basic tests)
cd mobileApp
npm install
npm test
```
