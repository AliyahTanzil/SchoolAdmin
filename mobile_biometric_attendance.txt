# School Admin - Mobile/Tablet Biometric Attendance
## Using Device Built-in Fingerprint Scanner (No Extra Hardware)

**Approach:**
- 🏫 **Gate Attendance** → Tablet/Phone mounted at school gate
- 📋 **Class Attendance** → Teacher's phone/tablet marks register
- 📱 **Parent Alerts** → Real-time push/SMS notifications
- 🔒 **Biometric** → Device built-in fingerprint (Touch ID / Android fingerprint)

**No Extra Hardware Needed!**
- Android phone/tablet: Built-in fingerprint sensor
- iPad/iPhone: Touch ID or Face ID
- Cost: $0 (use existing devices)

## DAY 16: Biometric Auth Service (Backend)

### STEP 1: Create Biometric Verification Service

💬 **YOU SAY TO GEMINI:**
```
Create backend/src/services/biometricService.js that handles
mobile device biometric authentication:

1. Class BiometricService with methods:

   enrollBiometric(studentId, deviceId, biometricType, rawBiometricData):
   - Hash the biometric data using bcrypt (NEVER store raw)
   - Check if student already enrolled on this device
   - Save StudentBiometric record
   - Return: { success, enrollmentId, message }

   verifyBiometric(deviceId, rawBiometricData):
   - Get all active students enrolled on this device
   - Compare provided biometric hash against stored hashes
   - Return matching studentId or null
   - Log verification attempt (success/fail)
   - Rate limit: max 10 failed attempts per device per minute

   generatePINBackup(studentId):
   - Generate 6-digit PIN as backup
   - Hash and store it
   - Return PIN to show once to student/parent
   - Used when fingerprint fails

   verifyPIN(deviceId, pin):
   - Find student by PIN hash
   - Return studentId if valid
   - Increment failed attempts counter

2. Security measures:
   - Never log raw biometric data
   - Encrypt all stored hashes
   - Automatic PIN expiry (30 days)
   - Device binding (biometric only works on enrolled device)

3. Error handling:
   - Biometric not enrolled → prompt enrollment
   - Too many failed attempts → temporary lockout
   - Device not registered → reject all requests
```

### STEP 2: Create Attendance Controller

💬 **YOU SAY TO GEMINI:**
```
Create backend/src/controllers/attendanceController.js with all
attendance management methods:

1. gateCheckIn(req, res):
   Input: { deviceId, biometricHash OR pin, checkInTime }
   Process:
   a) Verify device is registered and active
   b) Verify biometric/PIN → get studentId
   c) Check if student already checked in today
   d) Create/update StudentAttendance record
   e) Calculate if LATE:
      - Get school start time from SystemSettings (default 7:45 AM)
      - If checkInTime > startTime + grace period (15 min) → LATE
      - Calculate lateByMinutes
   f) Queue parent notification (GATE_ENTRY or LATE_ARRIVAL)
   g) Emit WebSocket event: 'attendance:gate:checkin'
   h) Return: { studentName, photo, status, checkInTime, message }

2. gateCheckOut(req, res):
   Input: { deviceId, biometricHash OR pin, checkOutTime }
   Process:
   a) Verify biometric → get studentId
   b) Find today's attendance record (must have checked in)
   c) Update gateCheckOutTime
   d) Calculate total hours in school
   e) Queue GATE_EXIT notification to parents
   f) Emit WebSocket event: 'attendance:gate:checkout'
   g) Return: { studentName, checkOutTime, totalHours }

3. markClassRegister(req, res):
   Input: { classId, sessionType, date, attendanceList: [{studentId, status}], teacherId }
   Process:
   a) Verify teacher has permission for this class
   b) Check session not already submitted
   c) Bulk update StudentAttendance records
   d) For MORNING session:
      - Set classCheckInTime for present students
      - Send ABSENT_ALERT for absent students immediately
      - Send CLASS_MORNING notification for present students
   e) For AFTERNOON session:
      - Set classCheckOutTime for present students
      - Send CLASS_AFTERNOON notification
   f) Create/update AttendanceSession record
   g) Return: { sessionId, present, absent, notificationsSent }

4. getClassRegisterForWeek(req, res):
   Input: classId, weekStartDate (query params)
   Return the weekly grid data structure:
   {
     weekDates: { monday: '2024-01-22', ... },
     students: [{
       id, name, rollNumber, photo,
       weekData: {
         monday: {
           morning: { status, time, method },
           afternoon: { status, time, method }
         },
         ...
       }
     }]
   }

5. getTodayGateFeed(req, res):
   Return real-time list of today's gate check-ins:
   [{ studentName, photo, class, checkInTime, status }]
   Sorted by most recent first

Include proper error handling, auth middleware (authenticate + authorize),
input validation, and comprehensive API response messages.
```
